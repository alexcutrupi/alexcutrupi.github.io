01 / Hosting & IT infrastructure

BlastHost

A hosting project associated with InstantBay, developed to support services such as Minecraft server hosting.

I worked on the servers, networking and website, gaining practical experience in building and connecting the different parts of a hosting platform.

Period
July 2025 – January 2026
My contribution
Server administration, networking & web development
Project type
Practical hosting and infrastructure development

My contribution

What I did

Set up and managed servers

Configured Linux servers, installed hosting services and worked with a game server control panel. Set up monitoring and firewall rules, and investigated service and access problems.

Developed the website

Built a custom Next.js website and deployed it to a Linux server. Worked on connecting it to a billing system so hosting packages could be retrieved automatically.

Connected the infrastructure

Configured VPN connections between home-hosted servers and a virtual private server. Gained experience with routing, port forwarding and diagnosing connectivity issues.

Built email services

Configured an independent email server and got database-backed mailbox authentication working. Tested email connections and worked through configuration problems.

Practical outcomes

What I achieved

Website build
Produced a successful production build of the website after resolving deployment and configuration issues.
VPN connection
Established and tested an OpenVPN connection from my Mac to the server.
Email authentication
Resolved database authentication problems so the mail server could authenticate a mailbox account.

The platform remained a development project, with some integrations and network configurations still in progress.

Skills developed

Learning through practical work

This project strengthened my Linux administration, networking and web development skills. I learned to investigate faults methodically, use logs to identify problems and test changes across connected systems.

It also developed my ability to learn independently and persist through unfamiliar technical problems — experience I want to build on through further study and practical work.
