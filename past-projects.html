01 / Hosting & IT infrastructure

BlastHost

A hosting project associated with InstantBay, developed to support services such as Minecraft server hosting.

I worked on the servers, networking and website, gaining practical experience in building and connecting the different parts of a hosting platform.

Period
July 2025 – January 2026
My contribution
Server administration, networking & web development
Project type
Practical hosting and infrastructure development

My contribution

What I did

Linux server administration

Configured a physical Debian server and worked with Ubuntu and virtual private servers. Installed services, managed permissions and investigated service startup and access problems.

Tools used: Debian, Ubuntu, Linux

Game hosting & control panel

Worked with Pterodactyl to manage game server infrastructure. Explored its Laravel-based application and frontend to customise the panel’s appearance and server layout for BlastHost.

Tools used: Pterodactyl, Laravel

Website development & deployment

Built a custom Next.js frontend using JavaScript and Node.js, with Tailwind-related styling tools and Turbopack. Deployed it on Linux using Nginx and systemd, resolving build and configuration problems.

Tools used: Next.js, JavaScript, Node.js, Tailwind tooling, Turbopack, Nginx, systemd

Billing integration

Worked on a WHMCS API integration to retrieve hosting packages for the website automatically. Configured API access and investigated IP restrictions; the full ordering and payment flow remained in development.

Tools used: WHMCS API

Networking & VPNs

Established an OpenVPN connection and configured WireGuard between home-hosted infrastructure and a VPS. Also experimented with GRE tunnelling, routing, NAT and port forwarding.

Tools used: OpenVPN, WireGuard, GRE tunnels

Email infrastructure

Set up an independent email server with Postfix and Dovecot, backed by MariaDB. Got mailbox authentication working, configured TLS certificates and tested SMTP connections.

Tools used: Postfix, Dovecot, MariaDB, Let’s Encrypt, Swaks

Monitoring & firewall configuration

Installed and configured Netdata for server monitoring and investigated how to restrict access to its dashboard. Used UFW to configure firewall access for services and VPN connections.

Tools used: Netdata, UFW

Practical outcomes

What I achieved

Website build
Produced a successful production build of the website after resolving deployment and configuration issues.
VPN connection
Established and tested an OpenVPN connection from my Mac to the server.
Email authentication
Resolved database authentication problems so the mail server could authenticate a mailbox account.

The platform remained a development project, with some integrations and network configurations still in progress.

Skills developed

Learning through practical work

This project strengthened my Linux administration, networking and web development skills. I learned to investigate faults methodically, use logs to identify problems and test changes across connected systems.

It also developed my ability to learn independently and persist through unfamiliar technical problems — experience I want to build on through further study and practical work.
